# 레이스 접수 보드

국내 메이저 마라톤·트레일 대회의 접수 시기, 공식 신청 링크, 접수 방식, 지난번 마감 속도를 한곳에 모은 페이지입니다.

- 2026년 / 2027년 접수를 연도별로 구분하고 대회별 접수 D-day를 표시합니다.
- 나만의 대회 추가, ☆ 내 대회 표시, 빠른 신청 키트(복사·붙여넣기)는 각자 브라우저에만 저장됩니다.
- 일정은 공식 공지를 기준으로 주기적으로 갱신합니다. 「예상」 일정은 지난 일정을 기준으로 한 추정이니 신청 전 공식 공지를 꼭 확인하세요.
